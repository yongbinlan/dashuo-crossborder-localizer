# 目标语字幕与目标语口播同步

适用于完整配音、段落恢复、换声或只修字幕。仅字幕通道保留原声及原时间轴，不按新旁白重排。

## 原因与执行

段落配音和字幕是两个时间轴。中文句子原先占几秒，不能推定外语同一句也在该秒开始；段落总时长合格不等于内部句界一致。`use_following_silence`和1.10倍上限只解决装入时长，不是逐句同步。

1. 锁定最终选中录音、实际边缘修剪量、每段起点及变速倍率。先完成声音适配，再安排目标字幕。已有正确录音时只修字幕，不重配整片。
2. 对当前录音做本地逐词识别以定位台词；将词时间换算到成片时间：段落起点 +（原词时间 − 首部修剪量）/ 实际倍率。对最终AAC再核对，防止选中候选或段落起点不一致。
3. ASR词首可能把前面数百毫秒静音包含进去。用实际波形、低阈值活动检测或本地VAD检查疑似起点；呼吸、弱辅音和噪声仍需核听。能量阈值不是通用音素边界；出现不一致不能直接全量采用ASR时间。
4. 逐句生成字幕开始和结束，适当留出阅读尾巴，避免下一句已经开口而上一句字幕仍显示。检查整片全部句子与段间切换，不统一平移整条。画面指代/动作仍检查，冲突先调整可用停顿或原获准段落安排，不能靠字幕掩盖旁白讲错画面。
5. 保存音频和字幕身份、句首/句尾依据。改字、补配、修剪、变速或换声后，旧对齐证据失效，重建受影响部分。仅改时间/排版时复制已校准AAC，由纯净原片一次烧录；保留旧版。

## v1.9.5实际代码覆盖

`localize.py run`在完整配音的`mix_dub`之后、视频编码之前，读取**已写出的ASS**，调用`scripts/subtitle_sync.py`，保存`subtitle-sync.json`。

- 实际ASS与计划逐句字幕一致：检查有序、不重叠、未越界，绑定当前旁白；结果仅为`assembled_clip_slots_only`，不能宣称自动逐词对齐。
- 实际ASS独立于计划逐句字幕：要求`render.subtitle_alignment_evidence`，校验旁白SHA、实际ASS事件与证据一致、目标文本完整且顺序一致、引用来源文件SHA有效、声音锚点有序。字幕起点与锚点差超过约0.20秒、提前结束超过约0.12秒、上一字幕跨过下一句起声约0.10秒则阻断。包含ASS百分秒舍入容差，这些是诊断默认值，不是人耳精度认证。
- 音频SHA改变、独立时轴没有依据、旧依据绑定别的ASS/来源时阻断；证据及来源身份进入缓存指纹，旧技术成功不代替新版检查。
- 外部适配器/只改字幕的修复脚本使用同一个`check`或CLI，不能跳过。当前不提供自动ASR/强制对齐生成器，未审听结果保持`verification_incomplete`。
- v1.9.8保留原中文硬字幕且目标同为简中华语、无需新增同文字幕时，不把空的新字幕层当失败；记录`retained_source_hardsubs_no_new_caption_layer`，原硬字幕与新配音的同步仍须实际检查，不生成同步通过结论。
- 原有仅字幕和CapCut分支不自动加载本地TTS/ASR，也不继承本检查器的技术结论。CapCut导出物仍对实际目标语声音另行验收。

## 独立时轴证据格式

`render.subtitle_alignment_evidence`指向：

```json
{
  "schema_version": 1,
  "audio_sha256": "当前校准旁白文件SHA256",
  "method": "asr_waveform",
  "reviewer": "实际执行者及检查范围",
  "sources": [{"path": "当前逐词识别或波形记录.json", "sha256": "该文件SHA256"}],
  "captions": [
    {"id": 1, "start": 0.04, "end": 1.40, "text": "实际显示文本",
     "target_text": "本条对应的目标语口播全文", "speech_start": 0.08, "speech_end": 1.30}
  ]
}
```

`target_text`仅在显示文本包含其他层（如双语）时需要，缺省使用`text`。完整目标文本按顺序与最终旁白逐字匹配（忽略换行空白），不做相似度放行。`method`可为`asr_waveform`、`listened`、`provided_aligned`，名称不证明实际听审，仍须保留真实证据。

单独修字幕时：

```text
python scripts/subtitle_sync.py --ass 新字幕.ass --planned 原计划显示.json --spoken 当前目标旁白.json --audio 当前校准旁白.wav --duration 原片秒数 --evidence 对齐依据.json --output subtitle-sync.json
```

`--planned`与`--spoken`均为JSON数组。命令只检查，不修改视频、调用模型或生成审核通过声明。

## 回归与验收

至少覆盖：旧错误时轴被拒、修复时轴通过、换音频后证据失效、字幕漏字/改字/乱序被拒、来源记录改动后失效，以及普通逐句/仅字幕不被误当成已完成逐词核听。

通过结构/锚点检查后，仍需实际看字幕、连续核听最终声音和段落衔接。ASR高相似度、两次同模型识别一致、波形图或VAD均不代替听音。没有可靠音频输入能力时，交付明确标注试听版、实际未核听及待用户检查的范围，不填写虚假的通过字段。

本次暖垫案例还发现：全文ASR与短段ASR会共同把词前停顿分配给词首；因此“多路识别同向”本身不能确认实际起声。最终修订依据ASR词序、实际波形与两档本地VAD共同定位，保留此前估计供追溯，不继续把旧词首当实听结论。
